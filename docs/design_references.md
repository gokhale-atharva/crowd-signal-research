# Reference-driven interface revision

The user supplied [awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos).
It is a prompt/video collection, rather than a ready-made finance application. Its
MIT repository license was inspected; individual creators retain rights to their
videos. No video or third-party interface source is copied into this project.

Two relevant references were read in full:

- [UI Motion Loop Design](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/prompts/flxrnc-251921.md): state continuity, deliberate motion timing and reproducible visual checks.
- [Widget Animation Motion Design](https://github.com/yihui-dev/awesome-opus5-5-videos/blob/main/prompts/khlaseek-dsgner-877659.md): staged information reveals and chart-path entrances.

Adaptation: a luminous cobalt analytics canvas, animated selected-company changes,
chart entrances tied to actual dataset selection, and clear depth/hierarchy. Avoid
continuous looping motion over financial values. Use Motion 14.10.1, downloaded
from the official npm package, with its MIT license retained alongside the vendored
runtime. Plotly provides actual chart interaction; all output remains self-contained.

UI/UX Pro Max `fintech analytics cinematic dashboard` returned a data-dense dashboard
style and analytics font pairing. Adopt filtering, linked charts and hover readouts;
discard its unrelated enterprise-sales conversion pattern. Preserve the user's
midnight / electric cobalt / acid-lime palette, keyboard controls and reduced motion.

Distinguish real price-only observations from the simulated social/news lab. A data
mode label and collection timestamp must remain visible. No animation may suggest
that a static captured snapshot is updating live.
