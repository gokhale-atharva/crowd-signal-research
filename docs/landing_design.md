# Landing page and navigation direction

Extend the current near-black/cobalt/lime spatial identity into a distinct public entrance.
The first screen pairs a large two-line product statement and clear workspace CTA with an
interactive 3D stack of research layers. Motion stages the entrance and separates/reassembles
those layers. Layer links lead to actual market, crowd and model pages. No fake streaming,
profit claims, social proof or unavailable live sentiment appears.

Navigation: index.html (landing); markets.html (exchange workspace); ten company-*.html
pages; community.html (crowd/news and rankings); validation.html (models and uncertainty);
methodology.html (how data and timing are handled). Company cards/table links navigate to
company pages. The landing's primary CTA opens the workspace in a new browser tab and says so.
Other site navigation uses normal links with active-page indication and preserves research
context via query parameters. HKEX/KRX standalone exports remain available.

Prefer shared cached runtime/data assets for the multipage site. Keep landing and legacy
exchange exports self-contained. Preserve offline file navigation and disclose snapshot
provenance. Desktop and narrow layouts both expose real page navigation.

The UI/UX Pro Max landing query was inspected: use its hierarchy and controlled entrance;
discard sales/contact patterns, badges and unrelated palette advice. Existing inspected
Skiper UI, Vengeance perspective, Animmaster catalogue and the video prompt's explodable
3D object inform interactions. All new code is original; no paid component source is copied.

Copy was revised alongside layout: the headline connects the layered scene to the product;
headings name a task; notices use short factual statements. No promises of returns or live
source access. Source/forecast limitations remain visible. Mobile price/currency and source
notes were adjusted after rendered review.
