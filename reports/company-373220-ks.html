04 / Under the surface

Follow the working.

01 — OBSERVE

Start at the source.

Apify supplies captured LIHKG and Telegram posts. Exa supplies dated company news. The source-status page records actual coverage and gaps; Market snapshot remains price-only. Posts pass duplicate and spam checks before scoring; positions require explicit long or short language.

02 — ALIGN

Use the right cutoff.

Exchange calendars determine session boundaries. Features use information available by the prior close; after-close posts enter the following session. Newly retrieved history is never treated as known earlier.

03 — VALIDATE

Test on later sessions.

Ridge and gradient boosting face random-walk and mean-return baselines. Five-session block bootstraps keep ticker groups together. Forecast intervals are empirical. Historical performance does not establish future accuracy.

Read the view in front of you.

The 3D terrain makes the shape of a price history visible. Use OHLC for exact axes, daily candles and nearby levels. Rotate with the controls or keyboard arrows; Reset restores the default view. Pause stops ambient motion.

Price levels have heuristic strength scores. They are not probabilities. Model estimates and empirical residual bands carry uncertainty.

Know where evidence ends.

Market snapshot contains genuine saved daily prices. Captured evidence includes verified source runs and dated news; coverage varies by company. Simulated lab uses generated prices, posts and news to exercise the software; it is not evidence of trading performance.

Why historical publication dates are not enough

A newly retrieved article was not necessarily available to the model in the past. Features use the later of publication and observation/retrieval time. Current engagement is never backdated.

Keep the test honest.

Ridge and gradient boosting use expanding windows with shared held-out dates. Fixed settings avoid tuning on the leaderboard. Price-only, social, news and all-feature variants face random-walk and mean-return baselines.

Five-session block bootstraps keep the five tickers together. Exploratory p-values are not corrected for multiple comparisons.

Separate a forecast from an outcome.

A genuine forward estimate is recorded before the target session opens. Its immutable file includes a timestamp, source commit and input hashes. Only a subsequently observed close can evaluate it.

No posts is not a neutral score.

A zero sentiment score means observed opinions balance out. A dash means there are no usable observations. We leave those two states separate.

A capture is not a history.

A new collection can show recent posts by publication date. That retrospective view uses captured engagement. Historical models only use observations available before the relevant market close.

Connect sources from the local project

This public report displays saved data. Collection runs from the Python project; keys stay in your local .env file.

  1. Copy .env.example to .env. Add APIFY_TOKEN and EXA_API_KEY. The LLM key is optional.
  2. Review public investor channels for both exchanges. Set them in exchange YAML. Both exchanges use LIHKG and Telegram; Exa supplies news.
  3. Run the setup check below. It lists every blocker before any source job launches.
  4. Run capped source probes and inspect timestamped, relevant post bodies. A configured actor is not a verified source. A successful run with zero relevant bodies is a coverage gap.
  5. Collect, analyse and export. Re-publish the generated report to update this site.
