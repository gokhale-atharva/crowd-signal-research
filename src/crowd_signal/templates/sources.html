No posts is not a neutral score.

A zero sentiment score means observed opinions balance out. A dash means there are no usable observations. We leave those two states separate.

A capture is not a history.

A new collection can show recent posts by publication date. That retrospective view uses captured engagement. Historical models only use observations available before the relevant market close.

Connect sources from the local project

This public report displays saved data. Collection runs from the Python project; keys stay in your local .env file.

  1. Copy .env.example to .env. Add APIFY_TOKEN and EXA_API_KEY. The LLM key is optional.
  2. Review public investor channels for both exchanges. Set them in exchange YAML. Both exchanges use LIHKG and Telegram; Exa supplies news.
  3. Run the setup check below. It lists every blocker before any source job launches.
  4. Run capped source probes and inspect timestamped, relevant post bodies. A configured actor is not a verified source. A successful run with zero relevant bodies is a coverage gap.
  5. Collect, analyse and export. Re-publish the generated report to update this site.
crowd-signal doctor --strict
crowd-signal run-all --exchange ALL --mode live
