How to read this workspace

The current checkpoint establishes the research universe, data contracts and report design. It contains no measured market results.

One calendar, one causal boundary

All post timestamps normalize to UTC and preserve their original timezone. Posts at or after the exchange close map to the next observed trading session; holidays come from a supplied calendar.

Sources must pass a real test

Store listings are candidates, not verified sources. A small Apify run must return relevant timestamped public posts. Telegram also needs suitable public finance channels.

Validation is planned, not complete

The model milestone will compare price-only, social, news and combined features against a random walk using expanding windows. Short social histories may not support a statistically reliable improvement.

Reproduce this checkpoint

From the project root, run crowd-signal doctor and crowd-signal replay. Replay validates synthetic parser fixtures and exports this preview without API keys or network calls.
